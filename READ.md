# ASTRA 1.0 — Mine Safety Robot

### Predictive AI Rescue Rover for Underground Mine Safety

This repository contains the current working prototype code for the ASTRA 1.0 mine safety robot developed for Smart India Hackathon 2026.

## Current Prototype

The current prototype includes an ESP32-based robot control system.

### Code Included

- `RC_Bot_Code_ESP32.ino` — ESP32 prototype control code

## Hardware

- ESP32-based control system
- Mobile robot platform
- Motor control system

## Prototype Status

This repository contains the current working prototype implementation.

Additional mine-safety sensing, communication, autonomous navigation and AI capabilities are planned for future development.
